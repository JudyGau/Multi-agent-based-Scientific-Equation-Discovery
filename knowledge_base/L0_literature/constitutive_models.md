# MRF 经典本构模型汇总（L0 层 · 供 Proposer 积木）

> 本文档汇总磁流变液（MRF）稳态剪切下的四类经典本构，重点关注**公式结构、参数物理含义、与颗粒几何(AR₁,AR₂,ψ)的耦合点**。
> 适用场景：椭球/立方体颗粒几何 → τ_y(B,φ,AR) 符号回归的候选骨架来源。

---

## 1. Bingham 塑性模型

### 公式
```
τ = τ_y(B) + η_p · γ̇ ,  |τ| > τ_y
γ̇ = 0              ,  |τ| ≤ τ_y
```

### 参数物理含义
| 参数 | 单位 | 物理来源 |
|---|---|---|
| τ_y(B) | Pa | 磁场诱导屈服应力，来自颗粒链剪切强度 |
| η_p | Pa·s | 后屈服塑性黏度（常取零场基体黏度 η₀ 量级） |

### MRF 适用性
- ✅ 工程阻尼器最常用（Spencer 改良 Bouc-Wen + Bingham）
- ❌ **γ̇→0 时 η 不发散**，但 MRF 实测有小振幅准固态（biviscous 才修）
- ❌ τ_y(B) 纯经验幂律 `τ_y ∝ B^α`，**无磁饱和形**

### 与颗粒几何的耦合点
- `τ_y` 隐含 `τ_y ∝ φ·M·H·f(链结构)` → 几何通过 **φ_max(AR,ψ)** 和 **退磁 N(AR)** 进
- 候选改写方向（LLM-SR 用）：
  ```
  τ_y(B,φ,AR) = C · [φ/φ_max(AR)]² · [M_s·(1−N(AR)·χ)]^α · B^β/(c+B^β)
  ```

## 2. Herschel-Bulkley（HB）模型

### 公式
```
τ = τ_y(B) + K · γ̇^m ,  |τ| > τ_y
γ̇ = 0               ,  |τ| ≤ τ_y
```

### 参数物理含义
| 参数 | 单位 | 物理来源 |
|---|---|---|
| τ_y(B) | Pa | 同 Bingham |
| K | Pa·sᵐ | 稠度系数 |
| m | 无量纲 | 流变指数：m<1 剪切稀化，m>1 剪切增稠 |

### MRF 适用性
- ✅ 比 Bingham 多一个自由度，能描述 MRF 的**剪切稀化**（多数 MRF 实测 m≈0.6–0.9）
- ✅ 工业配方拟合最常用
- ❌ 仍无磁饱和形（τ_y(B) 需外挂饱和函数）

### 与颗粒几何的耦合点
- `m` 可能**弱依赖于几何**：非球形(AR↑) 链柔度↑ → 剪切稀化更明显 → m 可能随 AR 微降
- `K` 与基体 η₀ 和 φ_eff 相关：`K ∝ η₀ · φ_eff^p′`
- 候选改写方向：
  ```
  τ = τ_y(B,φ,AR) + K(φ,AR) · γ̇^{m(AR)}
  ```

## 3. Casson 模型

### 公式
```
√τ = √τ_c + √(η_c · γ̇) ,  |τ| > τ_c
γ̇ = 0                  ,  |τ| ≤ τ_c
```
（注：Casson 原式为油漆流变学，MRF 抛光液常用）

### 参数物理含义
| 参数 | 单位 | 物理来源 |
|---|---|---|
| τ_c | Pa | Casson 屈服应力 |
| η_c | Pa·s | Casson 黏度 |

### MRF 适用性
- ✅ 抛光液（铁基 + 非球形磨料）场景多见
- ❌ 理论推导弱，纯经验结构
- ❌ 与 MRF 链模型物理衔接不紧

### 与颗粒几何的耦合点
- 结构 `√τ = √τ_c + √(η_c·γ̇)` 可视为 **Bingham 的平方根变体**
- `τ_c(B,φ,AR)` 可套用同 Bingham 的几何修正
- LLM-SR 可试：`√τ = √τ_c(B,φ,AR) + √(η_c(φ,AR)·γ̇)`

## 4. CCK 类模型（链结构模型，MRF 专属）

> 注：CCK 原指 Chin-Bullough-Clarke 磁流变变体（区别于金融的 Merton 模型），核心是**把链结构显式建模进本构**。

### 微观链起点（Klingenberg 系）
单链剪切屈服（Ferdman/Klingenberg 推导）：
```
τ_y,chain ∼ (3/2) · φ · M · H · sin²θ_chain
```
其中：
- `M ∼ φ·M_s(颗粒) · (1−N(AR)·χ)` —— **退磁 N(AR) 进**
- `φ` 有效体积 → **φ_max(AR,ψ) 进**
- `θ_chain` 链取向角，B 场下链沿场取向 → θ→0 → sin²θ→0，但剪切打破

### 宏观 CCK 形（示意）
```
τ_y(B,φ,AR) = C · φ_eff(AR)^p · [M_s·f_N(AR)]^α · B^β / (c + B^β)
```
- `f_N(AR) = 1 − N_long(AR)·χ/(1+N_long(AR)·χ)` 类（退磁稀释）
- `φ_eff = φ / φ_max(AR,ψ)`
- `B^β/(c+B^β)` 为 **Ginder-Davis 1994 饱和形**（磁饱和后 τ_y 平台）

### 与颗粒几何的耦合点（⭐ 核心）
这是 LLM-SR 挖的**主战场**：
1. **退磁通道**：AR↑ → N_long↑ → M_eff↓ → τ_y↓
2. **堆积通道**：AR↑(雪茄) 或 AR₂↑(扁盘) → φ_max↓ → φ_eff↓ → τ_y↓
3. **两通道权衡**：AR 从 1→3 链取向占优(τ_y↑)，AR>3 退磁占优(τ_y↓) → **τ_y(AR) 应有峰**
4. **立方体棱角**：同 AR 下 ψ<1 → φ_max 略降 + 链滑移摩擦↑ → τ_y 主项略低但 A_hys 反超

## 5. 动态/滞回族（LAOS 工况，立方体特色）

### Bouc-Wen 模型（MR 阻尼器工业标准，Spencer 改良）
```
τ = c·γ̇ + α·z
ż = A·γ̇ − β·|γ̇|·z − γ·|γ̇|·z
```
- `z` 为滞回变量，生成平滑滞后环
- Spencer 改良版把 `α,β,γ` 写成 B 的函数 → MRF 专属

### 与颗粒几何的耦合点
- **立方体棱角效应**主要体现在 `z` 的动态：棱-棱咬合 → 滞后环面积 ↑ → `β,γ` 可能随 ψ↓(棱角↑) 而 ↑
- 椭球链滚动 → 滞后环中等；立方体棱滑移 → 滞后环大
- **如果你的因变量选 A_hys(LAOS)，立方体 vs 椭球的差异在这最大**

## 6. LLM-SR Proposer 使用指引（RAG 消费端）

当 Proposer 检索到本档时，应按以下步骤改编候选式：

1. **选骨架**：从 Bingham/HB/CCK 三族选一（Casson 仅抛光液场景）
2. **拆 τ_y 为三因子**：
   - `φ_eff(AR,ψ,s)^p` —— 堆积通道
   - `M_eff(AR,s)^α` —— 退磁通道（椭球用 N(AR)，立方体 N=1/3）
   - `B^β/(c+B^β)` —— 饱和形（Ginder-Davis）
3. **立方体加棱角修正** `g_corner(ψ)`：
   - τ_y 主项：g≈1（弱影响）
   - A_hys：g 显著 >1
4. **参数自由度限制**：总自由参数 ≤4（19 点约束），优先锁 β≈1.8–2.0（文献值），让 SR 搜 p,α,c

### 候选式模板（直接给 LLM 当 seed）
```
# 骨架 A（退磁主导）
τ_y = k · [1 − N_long(AR₁,AR₂,s)]^{α} · B^{β}/(c + B^{β})

# 骨架 B（堆积主导）
τ_y = k · [φ_max_ref / φ_max(AR₁,AR₂,s)]^{p} · B^{β}/(c + B^{β})

# 骨架 C（乘积型，推荐首选）
τ_y = k · φ_eff(AR,s)^{p} · M_eff(AR,s)^{α} · B^{β}/(c + B^{β})
  其中 φ_eff = φ/φ_max(AR,s),  M_eff = M_s·(1−N(AR,s)·χ/(1+N(AR,s)·χ))

# 骨架 D（立方体棱角，仅 s=cube 时激活）
τ_y = k_s · φ_eff^{p} · M_eff^{α} · B^{β}/(c+B^{β}) · [1 + λ·(1−ψ)]
```

## 💡 几个设计点说明

1. **为什么每个模型都加"与颗粒几何耦合点"小节**——这是你这个课题和普通 MRF 本构综述的本质区别。普通综述只讲 `τ_y(B)`，你要把 `τ_y(B,φ,AR₁,AR₂,ψ,s)` 的**因子分解**讲清楚，LLM 检索到这段才知道"哦原来 AR 是通过 φ_max 和 N 两个通道进来的"，Proposer 才不会写出 `τ_y = a*AR₁ + b*AR₂` 这种量纲事故。

2. **候选式模板放文档末尾**——RAG 拉文档时，末尾的"LLM-SR Proposer 使用指引"那段权重最高（句子密度大、关键词集中），LLM 最容易把这几条骨架抄进 prompt。比让它从零想稳 10 倍。

3. **CCK 段是核心**——Bingham/HB 是工程拟合，CCK 才是"颗粒几何→磁流变"的物理桥。你 19 点 SR 的主战场就在 CCK 骨架 C 的 `p,α` 两个数 + `φ_max(AR)` 和 `N(AR)` 两个函数形，LLM 只要把这条挖出来，AICc 就能压住 HB。

4. **立方体棱角那段特意标"τ_y 主项 g≈1，A_hys 才显著"**——这是防 LLM 在 τ_y 主项里硬塞一个大的 `(1-ψ)` 修正然后过拟合。物理上立方体 τ_y 主项确实吃亏（M_eff↓+φ_max↓），棱角是**二阶修正**，A_hys 才是一阶。
